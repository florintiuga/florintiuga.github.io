Privacy policy

Event Assistant · last updated 2 November 2026

What the app does

Event Assistant is a personal Android app. It reads new emails in the email accounts you connect, finds events, bills, deliveries, tickets, trials and deadlines, and creates calendar events on your phone and, if you connect it, tasks in Asana.

Data the app accesses

  • Gmail (read-only, scope gmail.readonly): the subject, sender, date, text and PDF attachments of new emails. The app never sends, changes or deletes emails.
  • Outlook / Microsoft 365 (optional, Mail.Read): the same, for that account.
  • Your phone's calendar: to add, open and (only when you ask) delete events the app created.
  • Asana (optional): with a personal access token you provide, to create, open and (only when you ask) delete tasks.

Where the data goes

  • There is no server run by the app or its author. Processing happens on your phone.
  • To recognise events, the content of new emails is sent to Google's Gemini API using your own API key, under Google's terms for that key.
  • Events go to your phone's calendar (and from there to the calendar account you chose); tasks go to your Asana account.
  • Nothing is sold, shared with third parties or used for advertising.

Storage and deletion

Results, settings and the list of emails already checked are stored only on your phone. API keys and tokens are encrypted with a key that never leaves the device. Results are removed automatically after 60 days. Uninstalling the app deletes everything it stored. A backup file is created only when you choose to save one.

Google API Services User Data Policy

Event Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to show you events found in your emails, is not transferred to others except Google's Gemini API as described above, and is not used for advertising or by humans.
